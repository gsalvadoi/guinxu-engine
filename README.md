# guinxu-engine
A 3D software renderer I made from scratch with SDL2 for self-learning purposes.

## Controls:
- WASD --> Camera movement
- Z --> Toggle Z-buffer mode

## Features:
- Draw pixel
- Draw line
- Draw triangle (wireframe)
- Draw triangle (barycentric)
- Projections
- Basic transforms: translation, rotation (Y-axis) & scaling
- Z-Buffer
- OBJ model importer (trinagulated meshes only)
- Textures
- Alpha cutout (<0.5)
- Affine interpolation
- Perspective-correct interpolation
- Lambert diffuse light
- Phong specular reflections
- Free camera movement
- Draw UI text (only numbers)
- Backface culling

*Includes a simple original test character inspired by Super Mario used for demonstrating lighting and rendering features.*
